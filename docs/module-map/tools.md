# Tools

Commands for people; they prove nothing beyond the certificates they check.
`Examples/Tools.lean` and `Examples/Verify.lean` pin their output.

| Module | What it defines |
|---|---|
| `Tools/Show.lean` | Printers over the typed state: `SVal.fmt` (a fold, `fmtFold`), `fmtStorage`/`fmtStorageLine`/`fmtRoot`, `fmtTx`, `fmtHalt`/`fmtTRes` (a `THalt`; `exhausted` prints as `diverge`), a `Repr` of `State C Γ` for `#eval`; the clauses as written (`SpecExpr.fmt`). |
| `Tools/Common.lean` | Shared plumbing: the typed generator (`TGen`, `TGen.sval`/`storage`, canonical typed storages; `#difftest`'s and `#counterexample`'s), resolving `C` / `C.f`, evaluating terms, report layout; imports `Syntax`, not the closer's `Update`. |
| `Tools/Run.lean` | `#run C.f(args) [from σ] [with msg.sender := n, …]`: the typed run from a typed state (`State C []`; fresh, `freshState`, by default), `State.withTx`/`withRoots`; `#deploy C(args) [with …]`, a deployment by `Contract.deployT` (`Semantics/Deploy.lean`); `Prog.runT`/`localAfterT`, a scoped block run typed from a typed state (`State.exampleStore`, `State.testSuiteStore`: the examples' `#eval`s). |
| `Tools/Upstream.lean` | `#upstream_batch`: bounded, checkpointed replay of scalar/canonical-prefix typed ABI vectors, raw-calldata ABI coder v2 entries through the typed lazy/eager entry decoder (`Tools/UpstreamEntry.lean`), primitive v2 decoder checks and exact external-entry failure bytes through the typed importer/interpreter; separate working, broken and blocked evidence ([solidity-upstream-tests.md](../solidity-upstream-tests.md)). |
| `Tools/UpstreamEntry.lean` | The upstream replay's bridge to `Semantics/AbiEntry.lean`: parameter shapes and locations from a declaration, and the replay plan for one raw v2 vector (`revert`, `run` on canonical bytes, `blocked`, `legacy`); access-time calldata reads guarded in the replayed body (`accessOnly`, `guardDecl`, `accessGuard__calldata`). |
| `Tools/Inspect.lean` | `#wp φ`, `#step φ` on a scoped formula (`Fml C Γ`): the scoped strategy compiled, its result quoted and printed by `Delab`; the reduction (`Fml.reduceS`) and its printer (`LFml.ppWith`, a position printed by its binder's name: `Fml.keyNames`, `keyedNames`).  The module a file inspecting the calculus imports: it brings `Tools/ProofTree.lean` and `Tools/Taclet.lean`. |
| `Tools/Taclet.lean` | `#taclet r`: a scoped rule (`Taclet`, `LeanTaclet`, `CallbackTaclet`), its solkey taclets, printed rule and soundness (`toStep`), from the tables (`RuleShapes`, `PrintedRules`); `#check_rule_text`, that every rule of the three prints as a rule line. |
| `Tools/DiffTest.lean` | `#difftest C[.f]`: the typed run against `Evm/Compile.lean`'s code on random typed storages (`diffGen`, a `TGen`); the layout as a fold over the typed value (`encodeFold`, `ReprAt` read as a function; `mapKeysFold`). |
| `Tools/Counterexample.lean` | `Fml.eval3`, a scoped formula evaluated over the typed state and the typed run with fuel (`eval3_sound` against `holds`; by the recursor, its compiled twin `eval3C`), its leading parameters bound to a witness's arguments (`Fml.peel`), a typed candidate (`Cand C`, its state `Cand.tstate`) drawn by a typed generator (`TGen.sval`) and shrunk by folds (`intsFold`, `renameFold`), an update's result (`Upd.applyV`) lifted to a typed state it lands on (`State.lift?` over a global part and the locals' values, `TEnv.liftV?`), witness search and shrinking, certificates of `¬ ⊨ᶠ` of the scoped formula at the candidate's typed state, quoted (`quoteFold`, `Cand.quote`), `#counterexample`; programs run by `Prog.runA` (counting loops in closed form); long-array candidates (`longCands`: a dynamic-array root `2^255` or `2^256 - 1` long, `lazyArray`), certified by the kernel alone (`certifyLong`: `wt(storage)` proved, `proveMembersAllB`, the body evaluated) when the ordinary search finds nothing (`refuteLong`). |
| `Tools/LazyStorage.lean` | Storages too large to write down: `SVec.rep v n` (`n` copies, unfolded only as far as read), `wt(storage)` of one proved, not evaluated (`SVec.allB_rep`, `SVal.allB_arrayOf_rep`, `SFields.allB_cons_true`, `holds_wt_of`). |
| `Tools/Verify.lean` | `#verify C[.f]`: each spec'd function proved, refuted or given up on (`gaveUp`). |
| `Tools/ProofTree.lean` | `#proof_size` measures walk/leaf sizes (moved from the PolySize example); `#proof_tree φ`, `#proof_node n φ`, `#proof_tree_json φ` on a scoped formula: solkey's view of the tree of `⊢ φ` (`ProofTree.ofFormula`); `elabCoreFormula?`, the formula a command reads. |
| `Tools/LatexTerm.lean` | Scoped terms, updates and formulas rendered from their `Expr` as LaTeX: `Options`, the `plain` and `macros` backends, the symbol table `symbols` and its check `uncovered`, `definitionKeys`, `Doc` and its line breaking (`docs/latex.md`). |
| `Tools/Latex.lean` | The scoped calculus registered with vendored LeanTeX; formulas, sequents, chains, derivations (`derivationLatex`) and declaration statements to LaTeX strings/files; the options (`latexOpt`), `#latex_definition_targets`, `#latex_chains_files` (`scripts/latex-chains.sh`). |
| `Tools/LatexSolkey.lean` | `#latex_derivation` and `#latex_obligation`: a generated derivation, a `solc_import`ed function's obligation (`scripts/latex-sol.sh`). |
| `Tools/Elementary.lean` | Bounded capture/update traces built from `Calculus/Elementary.lean`'s laws. |
| `Tools/ProgramTrace.lean` | Checked formula/chain/obligation traces with ordered read continuations: `#latex_program`, `#latex_program_file`, `#program_trace_json_file`, `ProgramTrace.generate`. |
| `Automation/H28/Chain.lean` | Bounded automation-benchmark checkpoint; typed scope and retained obligations are stated in the module. |
| `Automation/H28/Context.lean` | Bounded automation-benchmark checkpoint; typed scope and retained obligations are stated in the module. |
| `Automation/H28/Prove.lean` | Bounded automation-benchmark checkpoint; typed scope and retained obligations are stated in the module. |
| `Tools/VerifierMetadata.lean` | Additive kernel facts tying each reported `postFails` index to the exact typed false postcondition clause and final run state; no source span, original-obligation or candidate association is inferred. |

| `**/*Controls.lean` | Library membership (t2-controls-off-path): every `*Controls` module is in `Solidity`. `scripts/coord-tools/controls-classify.py` lists those no library module imports; `REGISTER_CONTROLS_SPLIT=1 register.sh` (off by default) would move them to a `SolidityControls` root once CI and the axiom audit cover it. |
