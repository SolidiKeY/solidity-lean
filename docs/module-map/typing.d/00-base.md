# Typing and sort faithfulness

| Module | What it defines |
|---|---|
| `Typing/Values.lean` | Typed storage values, hereditarily: `Hered` (a condition per node kind) and `SVal.All P`, a fold with `eqns`; what every such predicate shares: reads (`SVal.findM_all`), defaults (`SVal.dflt_all`, the defaults' equations `SVal.dflt_struct` … by fuel independence, `SVal.dfltBelow_irrel`, which `Theory/Typed/Mem.lean` reads too), saves along keys a program writes and live word slots (`SVal.saveM_all`, `Path.Keys`, `SVal.Live`), `strip`/`defaultOf`/`overlay` (`Hered.StripOK`, `DelOK`, `OvOK`), copies out of memory (`SVal.Plain`, `MVal.copyMToSt_plain`), implications (`SVal.all_mono`, `Hered.Mono`); the save algebra (`SVal.saveM_idem`, `SVal.saveM_saveM`); a test that decides a predicate (`HeredB.Decides`, `SVal.allB_iff`). |
| `Typing/Soundness.lean` | `RunInv`, the shape of a run invariant: a part on the storage (`Storage C`), a part on each local at its type, kept as the heap grows (`loc_wk`). |
| `Typing/TypedRunInv.lean` | A `RunInv` read of a typed state (`RunInv.HoldsT`: `σ.storage`, and `TEnv.All` over the locals at their types) and carried along the typed run (`RunInv.TKeeps`): the scopes keep any (`tkeeps_seq` … `tkeeps_tryCall`, a loop by `TLoop.run_induct`; a call's and a `try`'s locals by `RunInv.ValMemOk`). |
| `Typing/HeredRun.lean` | A hereditary predicate the typed run keeps, statement by statement (`Stmt.keeps_all`, `Prog.run_all`): `HeredRun P G`, what each storage operation asks of the node conditions (`G` a property of the contract's types, `Ty.okDeep` for tightness); `heredInv` (the storage's `All P`); the storage operations (`Storage.save_all` … `pop_all`), resolved references live (`Loc.resolveT_live`); each leaf on `TRun.*`, once for the three predicates. |
| `Typing/Sorts.lean` | Runtime sorts of typed values (`SVal.keySort`, `MVal.keySort`: a word's by its type, a storage node `Struct`, a memory reference `Identity`), read by `SortCheck/Faithfulness.lean` and `Counterexamples/StaticRuntimeSort.lean`. |
| `Typing/Reachability.lean` | Every reachable storage is canonical (`canonH`: a mapping's keys distinct, its default the type's, at every node; `Prog.run_canon`, `reachable_canon`); `Reachable` is a scoped program's typed run from `State.init`; `map_default_not_reachable`, `map_dup_key_not_reachable`. |
| `Typing/Tight.lean` | Tight storage (`tightH`: no slot of an array of elements without a well-formed default, cleared words past an array's end, no entry of a reference-keyed mapping), kept for every contract (`Prog.run_tight`, `reachable_tight`, using `SRef.okDeep` from its declaration certificates); `SVal.Fits` (`fitsH`), what the builder writes with literals. |
| `Typing/Fits.lean` | Decision 77's conditional form: under `FixedFits` (every fixed size at most `2^256`, solc's "type too large for storage") every reachable storage fits (`reachable_fits`): the bounded run invariant (`bndH`: a dynamic array's slots below `2^256`, `reachable_bnd`) and the fixed sizes from the types (`Storage.fits_of_bnd`). |
| `Typing/Constructibility.lean` | The converse: canonical and tight is reachable for keys and slots that fit (`canon_reachable`; `reachable_iff`, `reachable_iff_fits`, `no_hidden_invariant`): the builder `Build.rootsProg`/`fill` runs by the typed run (`TRuns`, `run_push` … `run_bound`) to the storage it is given (`fill_ok`), tracked as saves at one path (`Wrote`); `dirty_word_not_reachable`, `huge_reachable_not_fits`, `bool_key_reachable`, `dangling_slot_reachable`. |
| `Typing/CanonTest.lean` | What the tests of `wt(storage)` (`Semantics/StorageWt.lean`) decide, by `SVal.allB_iff` (`Typing/Values.lean`): canonical and tight (`SVal.canonB_iff`, `tightB_iff`), `Storage.shapeB_iff`. |
| `Typing/CleanTail.lean` | Clean array tails (O6): `SVal.OrdinaryDefault` (a word at its default, a dynamic array of length `0`, a mapping anything), `Storage.CleanTail` (`cleanTailH`: every shadow one), what keeps it (`Storage.init_cleanTail`, `SVal.defaultOf_cleanTail`, `SVal.emptyPush_ordinaryDefault`, `SVal.find_cleanTail`), `Storage.cleanTailB_iff`; as the observations show it (`Path.KeyFree`, `SRef.Shadowed`, `TSto.CleanTails`, `Storage.cleanTails_obs`), the Theory's reading of `cleanTail(s)`. |
| `Typing/CleanTailRun.lean` | Clean tails as a contract's invariant (O6): `SVal.LiveAll`, `Storage.Grows`, the storage operations at live slots keep clean tails (`SVal.saveM_ct`, `Storage.push_ct` …), the invariant `CTInv` (clean storage, aliases live), the check `Stmt.ctSafe`/`Prog.exposesNone` and its soundness `Stmt.keeps_ct`, `ReachableBy.cleanTail`. |
| `SortCheck/Annotations.lean` | The taclets' read-sort annotations, transcribed from the `.key` file. |
| `SortCheck/Parser.lean` | Token-level `.key` scanner and the `conforms` cross-check. |
| `SortCheck/Faithfulness.lean` | Each annotation holds of what the typed run's evaluators read in every typed state, at the value's runtime sort (`Read.SortOk`, `Read.sortOk`, `Typing/Sorts.lean`), at every statement its `Taclet` rule fires on (`faithful_theorem`, the statement read off the constructor's type). |
| `SolkeyCheck.lean` (root) | `lake exe solkeycheck`. |
| `SolCases.lean` (root) | `lake exe solcases`: deterministic bounded cases as JSONL; the seed rotates the boundary pool. |
| `Counterexamples/*.lean` | Three refutation modules pinning design decisions: `DeleteFamilyGenericOverlap`, `StaticRuntimeSort`, `PreFixSortAnnotations`. |
| `Examples/Tactics/SignedCasts.lean` | Casts between `uint` and `int` and signed `unchecked`, through `int(u)`/`uint(i)`: solkey's `SolcTypesOpen`/`SolcArithmeticOpen` cases. |
| `Examples/Tactics/SolcOpen.lean` | What solkey's `solc/open` ports needed of the elaborator: `E(x)` asserts a member, a call's value has its callee's return width under `unchecked`. |
| `Examples/Tactics/StorageDangling.lean` | solkey's dangling-storage suite: an empty push saves only the length, so a popped alias's writes are exposed again; the four obligations derived in every state by `sol_prove`. |
