# The data-structure theories

solkey's `find`/`save`/`read`/`write` are uninterpreted symbols whose meaning is
a taclet set. These modules are that theory on typed values, each taclet a
law stated under its solkey name.
The map from taclet to theorem is `docs/lean-key-rule-map.md`.

| Module | What it defines |
|---|---|
| `Theory/Typed/Obs.lean` | The typed Theory: a value is its observations (`Obs L`: word, live length, presence, at the locations `L`), `TVal T`, `TSto C` over `SLoc C` (a state variable's path or a dangling one); `find`/`save`/`delAt`/`copyTo`/`push`/`extend`/`pop`/`select` stated once over any location family (`ObsLoc`), a delete/strip/copy computed from the type (`TVal.del`, `strip`, `overlay`, one `Comp`onent at a time); the bridge from the typed storage (`SVal.obs`, `Storage.obs`, `obs_save`, `obs_write`, `obs_delete`, `obs_push`, `obs_pop`, …).  Split by topic into the pieces below (`docs/parallelism.md`), this module the umbrella. |
| `Theory/Typed/Obs/Paths.lean` | Typed paths, observations, storage locations, typed values read below a path. |
| `Theory/Typed/Obs/Values.lean` | Values and storages as their observations, a read step by step, the bridge of delete/strip/copy. |
| `Theory/Typed/Obs/Ops.lean` | Under a `select`, the storage operations, their bridge and laws. |
| `Theory/Typed/Mem.lean` | The Theory of memory, typed: solkey's memory laws on the typed heap (`Grown H`, `MAddrT T`): a write read back and its frame (`Grown.writeT_facts`), a grown heap keeps the older objects (`Heap.Keeps`, `SVal.keeps_copyStToM`, `Heap.Keeps.readAddr`, `Grown.read_then_old`, `Grown.readId_then_old`) and an allocation's freshness (`Grown.alloc_id_ge`), a fresh object's defaults and lengths (`Heap.Dflt`, `Heap.dflt_allocDefault`, `Heap.allocDefault_array_len`, `newArrT_copy_len`, the defaults' equations from `Typing/Values.lean`), copies between storage and memory (`SVal.copyStToM_field`, `MVal.copyMToSt_field`, `MVal.copyBelow_eq` by `MVal.copyAt_congr`); no erasure is read; the section "The laws by solkey's taclets" restates each under its taclet's name, a `\else` as its `Frame` (`Grown.readOnWrite`, `Grown.readOnWriteFrame`, `Grown.readOnAddMFrame`, `Heap.initMember`, `Heap.initSize`, `SVal.readFromCopyToStorage`, `Grown.readFromCopyToStorageFrame`, `MVal.findOnCopy`; Lean only, `Grown.alloc_fresh`). |
| `Theory/Typed/MemMirror.lean` | A copy into memory below its root: `SVal.Mirrors` (an object holds what the storage value held, member by member, past a heap), kept by allocations (`SVal.Mirrors.wk`) and made by `SVal.copyStToM` (`SVal.mirrors_copyStToM`); read at a member and an element (`SFields.Mirrors.get`, `SVec.Mirrors.getElem`). |
| `Theory/Typed/Leaves.lean` | The leaves of a type (`Ty.leaves`: words by members and in-range fixed indices, fuel by `rankBound`; `Ty.leafCount`; `Ty.mem_leaves` by `Path.direct`/`Path.out`; disjoint, `Ty.leaves_strip?_ne`, `Leaf.diverges`), finite shapes (`Ty.Finite`, its test `Ty.finiteShape`), and the expansions they give: in the Theory under `TVal.Shaped` (`SVal.obs_shaped`, `Storage.obs_shaped`) a delete and a copy are a word written per leaf (`Obs.delAt_expand`, `Obs.copyTo_find_expand`); in the interpreter unconditionally at a shape with a leaf (`Storage.delete_expand`, `Storage.write_expand`, `Storage.write_find_expand`); a push and a pop of a word (`Obs.push_prim`, `Obs.pop_prim`, `Storage.push_prim`, `Storage.pop_prim`). |
| `Theory/Segs.lean` | Two paths of segments that part (`Theory.diverges`) and the segment a length is read at (`Theory.lengthSeg`), what the frame rules' side conditions read; list functions on segments. |
| `Theory/Bridge/Denote.lean` | What a typed symbol denotes in the typed Theory (`Srt.TDen C`: a word an `Option`, a path an `SLoc`, a storage a `TSto`, a stored value a `TVal`; `Op0.denote` … `Op3.denote` over `Storage.obs`) and the bridge to its typed evaluation (`Srt.Bridge`, `Op0.denote_eval` … `Op3.denote_eval`: the value read as its observations, literally). The only Theory module that imports the signature directly; `Theory/Typed/Mem.lean` reads it (`MAddrT`, `Grown.writeT`) through `Calculus/StateFacts.lean`. |
| `Theory/CallerModel/Static.lean` | Caller models that change nothing (O11): `CallerModel.Inert`, `inert_staticOnly`, `Reentry.reach_eq`, `Reentry.inert` (no unguarded entry); a transfer's one run (`ExecSM.transfer_inert`), `Stmt.isTransfer`, `Prog.inertSafe`, `Stmt.eq_run_inert`, `ExecPM.eq_run_inert`; a box read deterministically (`holdsR_box_inert`). |
