# Assurance boundary

Code and tests define the available checks. Run the verification commands in
[contributing.md](contributing.md#checks); the declared model assumptions are
[correctness.md](correctness.md) and [options.md](options.md).

A source proof, successful admission check, native verifier result and
executable-EVM correspondence are different results. Keep the theorem's exact
hypotheses and trust assumptions when reporting any of them. A green component
check does not discharge the full-pipeline obligations in
[coverage-plan.md](coverage-plan.md).
