# Source calldata slice conversion

`Backend/MemoryOps/SourceCalldataSlice.lean` consumes the existing resolved `slice`, `Source.sliceR`, implicit conversion and `Source.cdToMem`; it adds no evaluator, decoder or copy operation. Initial root/start/end local alignment derives actual expression execution at horizon `fuel+2`, then actual slice-plus-copy at `fuel+3`. The array, start and finish operands are evaluated in the original Source order in both pipelines, including the finish operand when `toEnd` is true. Bounds are against the original reference: reversed or overrun slices revert with the existing empty payload before decoding/allocation. Successful slicing retains its calldata identity with computed offset `off+32*start` and length `stop-start`.

`source_uint_slice_copy_window` equates that actual execution with the existing copy helper on the computed shifted window. It is not a generic decoded-list drop/take theorem. The unconditional theorem matches the computed decoder, deriving allocation only from decoded success. Its decoder-error branch is conditional; the controls do not supply a malformed uint-word witness. Natural offsets here are exactly the existing Source semantics, not a physical wrapping-address theorem or ABI entry admission.

The controls directly apply the new laws and existing paired-copy and checked-transfer producers. Populated input `[2,0,max]` slices to `[0,max]`; the old `[7,0,max]` object, two retained old aliases and independent `[8,9]` neighbour survive. Complete ordered Source object tables, all locals, native object contents, identities, allocator-next observations and Source world/events/logs/function-locals are retained. The actual intermediate slice execution leaves the input state unchanged. Empty exact-end, omitted end with finish zero, reversed/overrun, insufficient horizon and stale unsliced/old-root observations discriminate the results. An actual discarded-result statement runs at `fuel+4` with the original parameter count. Empty/toEnd controls are Source-only, not separate paired empty/length33 native instantiations.

All nine public laws/controls have exact standard-only axiom guards. Local per-file and changed-closure validation are recorded in the checkpoint evidence; full lane/default/TestSuite closure remains a separate obligation. This component supplies no intrinsic-local Prog, target word/byte copy run, whole target StateRepr/allocator/stack certificate, external compiler/EVM evidence, general graph/liveness, storage/deep-copy or whole-lane theorem. Existing failed global documentation/inventory gates remain failures separately from baseline comparisons. The original persistent goal is unchanged.
