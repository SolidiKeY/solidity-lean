# Runtime frame interpretation

[Authoritative source](../../Solidity/Backend/InternalFlow).

The frozen dual-outcome V3 contract is uninhabited for sources that never bare-revert; do not weaken its fields to admit success-only sources. The authorized success-only companion is separate. Recursive unrolling reduces obligations to per-body ordinary calls but does not prove those calls. Allocation/unwind ownership, complete saved frames and source-resource provenance must come from the same actual run.
