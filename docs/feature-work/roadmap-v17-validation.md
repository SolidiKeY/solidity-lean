## H125 Source dispatcher checkpoint

`Solidity/Backend/StructuredFlow/SourceDispatch.lean` provides executable `SourceDispatch.dispatch` from the existing resolved `Source.RStmt` to the actual `Evm.Compiler.compile` entry. `recognize_none_iff` states its exact syntax domain, and `recognize_plan_exact` reconstructs the original plan without an extra recognition premise. `mapping_exact` preserves each selected theorem's original slot equations. `dispatch_template_complete` proves actual entry coverage for every selected template; `program_admitted` discharges core admission rather than adding a domain restriction. Only syntax or incompatible operand mappings can produce an error (`dispatch_error_boundary`).

| Original Source family | Exact covered form |
|---|---|
| AssignmentBlocks | A finite block of Boolean local-to-local copies, including arbitrary list length and the empty list. |
| ConditionalStatement | Local-copy Boolean condition; both branches copy locals at the same Source type. |
| ConditionalSequence | That conditional followed by one local copy. |
| ConditionalReturn | That conditional followed by bare return. |
| ConditionalReturnContinuation | The preceding returning block followed by an arbitrary skipped Source tail. |
| ReturnTail | Local-copy condition with bare-return body, followed by one local copy. |
| ReturnPair | ReturnTail followed by another local copy. |
| WhileBreak | Local-copy Boolean condition with immediate break. |
| WhileContinue | Local-copy condition; body clears that same donor to false, then continues over an arbitrary skipped tail. |
| WhileReturn | Local-copy condition with immediate bare return. |
| ForBreak | One Boolean-copy initializer, absent condition, immediate break; arbitrary skipped post. |
| ForContinue | Skip initializer, local-copy condition, continue over a skipped tail; post clears the same donor to false. |
| ForReturn | Skip initializer, local-copy condition, immediate bare return; arbitrary skipped post. |
| DoWhileBreak | Boolean copy then break, with no further body item; arbitrary skipped condition. |
| DoWhileContinue | Boolean copy then continue over an arbitrary skipped tail; literal-false condition. |
| DoWhileReturn | Boolean copy then bare return, with no further body item; arbitrary skipped condition. |
