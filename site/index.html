About these examples

Each page is a file of solidity-lean, a Lean 4 model of solkey's calculus for Solidity. The infoview shows what Lean's language server answered when the site was built: the messages of the file, and the goal at the end of each line, as the editor would show it with the cursor there.

The pages are read-only: GitHub Pages runs no Lean. To edit and re-check an example, clone the repository and open it in an editor with the Lean extension: 

git clone https://github.com/SolidiKeY/solidity-lean
cd solidity-lean
lake build Solidity
code Solidity/Examples/Tactics/Tour.lean

The Velvet examples come from the optional Bridge package (cd Bridge && lake exe cache get && lake build Velvet).
