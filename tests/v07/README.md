# V07 lane checks

Rescued from the Codex VM (commit `9af754b1` on `origin/cloud/v07-move`, H46).
Each `*Checks.lean` and `EffectFixtures.lean` is a standalone check over the
`Solidity.Lowering.V07` library: open it in the Lean server (or
`lake env lean FILE`) after `lake build Solidity`. `check-effect-fixtures.mjs`
compares the ordered observation table in `EffectFixtures.lean` with
`effect-fixtures.expected.txt`.

Bulk kept off the branch tip (H44), listed with checksums in `BULK.sha256`:
the generated 1598-guard pin file `Axioms.lean`, its registry
`axiom-pins.json`, `proof-clients.json` and the exact-registry checker
`check-pins.mjs` (+ test). They were never registered in a library; tracking
`Axioms.lean` would add 1598 duplicate entries to the global axiom-pin gate,
whose inline `#guard_msgs` pins in `Solidity/Lowering/V07/` already cover the
headline theorems. Restore and verify with

    git checkout 9af754b1 -- tests/v07/{Axioms.lean,axiom-pins.json,proof-clients.json,check-pins.mjs,check-pins.test.mjs}
    sha256sum -c tests/v07/BULK.sha256

The registry describes the V07 modules as of `06852514`; modules added later
carry their own inline pins.
