# Portable evidence verification

Run from the repository root. The committed `evidence-manifest.json` is a
compact H44 descriptor: path, byte size and SHA256 for the external detailed
manifest and historical evidence archive. Bulk data and the expanded per-file
inventory remain off git. Absolute VM paths are location hints; downloads may
be stored elsewhere.

Without the detailed manifest, this reports `pending_artifacts` and exits 2;
no checkout or evidence verification is claimed:

```sh
python3 scripts/h62/item6/migrate-testsuite/verify-evidence.py
```

Supply the pinned detailed manifest and historical archive at local paths:

```sh
python3 scripts/h62/item6/migrate-testsuite/verify-evidence.py --detail-manifest /path/to/detailed-manifest.json --archive /path/to/evidence.tar.gz
```

The descriptor authenticates the full manifest before it is used. All existing
checks remain: 333 pinned closure sources plus 23 lane tools/fixtures, then the
archive bytes and all 17 required members, streamed without extraction.
Alternatively replace `--archive` with `--evidence-root /path/to/evidence` to
verify already-unpacked files. Paths inside the full manifest are relative.
Missing external inputs remain pending; present hash mismatches fail. Other
historical archive members are not interpreted.

This proves byte integrity/source provenance only. New compilation, 104
compiler-only signatures, export visibility, shims, H78 parity, full comparison
and root final gates remain pending. No Lean job or runtime gate is started.

`public-api-report.py` replays a relocated inventory with `--artifact-root`
and `--recorded-root` (the detailed manifest's historical capture root). Its
other input files are listed in `evidence_files`. Captured paths are checked
as data, never executed; output provenance paths are relative.

Regenerate the full manifest off git with `make-evidence-manifest.py
--evidence-root /path/to/evidence --archive /path/to/evidence.tar.gz` and redirect
stdout to an external file. Repeat with `--descriptor-for` naming that file to
emit the compact descriptor. Generation checks pinned closure hashes and
requires the detailed file to match regenerated bytes. Nondeterministic
measurement logs are authenticated historical artifacts, not promised bytewise
reproductions.
